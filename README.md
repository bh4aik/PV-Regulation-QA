# 💊 药物警戒法规 AI 问答库

中国药物警戒 / 药品安全相关法规的人工智能问答库，本地运行（Node.js 后端 + 网页前端，无构建步骤）。

## 功能

| 功能 | 说明 |
|---|---|
| 🔐 **账号体系** | 注册/登录（用户名或手机号），首个注册账号自动成为管理员；管理员可管理用户、查看用量分析 |
| 🤖 **智能问答** | 中文 BM25 检索 + DeepSeek API 流式生成，回答引用具体条款（如【《药品管理法》第三十三条】），点击引用可直接跳转法规原文；Markdown 格式渲染 |
| 🕘 **问询历史** | 每次问答自动保存；普通用户仅见自己的历史，管理员可查看全部 |
| 📚 **法规库** | 已收录 81 部中欧法规与指导原则（3582 条），全文查看、搜索、筛选；增删仅限管理员 |
| 📤 **上传入库** | 管理员上传 txt/md/docx/pdf 法规文件 → AI 清洗为结构化条款 → 核对后确认入库 |
| 🕷️ **每日爬虫** | 每日定时到各官网检查新发布的法规 → 去重 → 人工确认 → AI 清洗入库（默认源：安徽省药监局 TRS 公开接口） |
| ⚙️ **设置** | DeepSeek API Key / 模型、爬虫计划（cron）、数据源配置（仅管理员） |
| 📊 **管理控制台** | 用户管理（禁用/启用/角色/删除/重置密码）+ 用量分析（累计/今日问答、每日趋势、用户排行） |

## 快速开始

```bash
# 1. 安装依赖（Node.js 22+）
npm ci

# 2. 启动
npm start
# 或开发模式：npm run dev

# 3. 打开浏览器 http://localhost:3000
#    「注册」第一个账号 → 自动成为管理员
#    （也可在 .env 配置 ADMIN_USERNAME / ADMIN_PASSWORD 预置管理员）

# 4.（可选）配置 DeepSeek API Key —— 管理员登录后在「设置」页填写，
#    或复制 .env.example 为 .env 填写 DEEPSEEK_API_KEY
```

> 端口可用环境变量 `PORT` 修改。用户数据存储于 `data/state/users.json`（密码为 scrypt 加盐哈希，不明文保存）。新密码要求 12-128 位。

## 登录方式说明

- **开箱即用**：用户名 + 密码注册登录；注册时可绑定手机号，之后可用手机号直接登录。
- **微信登录**：需要微信开放平台企业认证 + 已备案域名，本地/内网部署无法直接接入。系统已预留第三方登录扩展点（`server/routes/auth.js` 中可增加 OAuth 回调路由），具备资质后可按微信官方 OAuth2 文档接入。
- **短信验证码登录**：需要短信服务商（阿里云/腾讯云 SMS）账号与签名审核。当前以「手机号 + 密码」作为等价替代；如需验证码流程，可在注册/登录接口中接入短信服务。

## 安全边界

- 公网部署必须预置管理员并设置 `AUTO_FIRST_ADMIN=false`。
- API Key、用户、会话和问答历史均保存在服务器 `data/state/`，请限制目录权限并加密备份。
- 用户问题与召回的法规片段会发送给 DeepSeek；不要输入个人敏感信息或公司机密。
- 爬虫只允许 HTTP(S) 公网地址，并限制响应体大小和重定向次数。
- 本项目提供法规检索辅助，不替代官方原文、法律意见或监管机构解释。

## 爬虫说明

- **默认数据源**：安徽省药监局（TRS 标签接口，`POST /site/label/8888`），该站持续转载国家药监局文件。`data/state/sources.json` 中可增改，支持两种类型：
  - `trs-label`：TRS 公开信息接口（需 url + form 参数，含 siteId/organId/catId）
  - `html-list`：普通静态列表页（需 url + selectors.link）
- **受限来源**：国家药监局官网（nmpa.gov.cn）和多数部委网站启用 JS 反爬（瑞数/412），服务端无法直接抓取。这类来源建议：① 用转载的省级药监局/公报页面；② 手动下载后上传；③ 在「清洗任务」页"手动添加候选"粘贴链接。
- 去重基于 URL（`data/state/seen-urls.json`），已忽略的不会重复出现。
- 定时默认每天 09:00（可在设置页改 cron），也可随时点「立即检查」。

## 常见问题

- **没有 DeepSeek Key 能用吗？** 能。问答显示检索到的相关条文（无生成式回答）；清洗自动用启发式解析（第X章/第X条正则 + 段落回退）。
- **上传的 PDF 解析不了？** 仅支持文本型 PDF（扫描件需先 OCR）；.doc 旧格式请另存为 .docx。
- **清洗结果不理想？** 配置 API Key 后清洗由 DeepSeek 结构化抽取完成，质量显著更高；入库前有预览核对步骤。
- **想收录更多法规？** 在「清洗任务」页手动添加候选链接，或上传文件；也可以把原始全文放进 `data/raw/` 后运行 `node scripts/ingest-raw.js`。
